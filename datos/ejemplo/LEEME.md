# Datos de ejemplo

`noticias_ejemplo.csv` es una descarga real del 19/11/2026 (caso de ejemplo: Presupuesto 2027, últimos 7 días), con títulos, medios, fechas y links. Sirve para practicar si Google News no responde en clase:

```
python herramientas/clipping.py --csv datos/ejemplo/noticias_ejemplo.csv
```

No lo usen como datos de su trabajo: descarguen los propios con `python herramientas/noticias.py`.
